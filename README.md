# MATLAB Linear Algebra

# Goal 
The goal of this project was to develop learning modules for students encountering concepts from linear algebra for the first time. By supplying students with real-world examples
and hands-on exercises, the modules may be able to help students better understand important theoretical concepts that might otherwise feel convoluted and distant. 

# Materials 
Three modules were developed covering topics of varying difficulty. The module titled Linear_Systems covers how the Gauss-Jordan reduction method is used to solve systems of linear equations, using the theoretical economic concept of general equilibrium as an example of how many aspects of the world can be thought of as a linear system. This module is intended for individuals who are just beginning to learn linear algebra and have no prior knowledge of the subject. The module titled Markov Chains describes Markov systems using the Lake model of unemployment as a practical example. Finally, Portfolio_Theory explores linear algebra as a cornerstone of quantitative finance, focusing on showing how linear algebra can be used to describe seemingly complex functions of our world in realitivly simply mathematcial terms. 

# Note 
The data.mat file contains real-world securities data intended to be used in the portfolio theory module.
